Task Instructions: Implementing and Completing the `DishWasher` Class

Objective:
Your task is to complete the implementation of a `DishWasher` class that simulates the operation 
    of a dishwasher. The class should be able to run a full wash cycle, track water consumption, 
    and calculate the total energy used during the cycle.


HELPFUL TIPS:
  -after implementing the print status method you should use it to print the status of the dishwasher 
  after each step in the runFullCycle method to make sure that the dishwasher is working correctly.
  -you can then create a dishwasher in the main class and call the methods individualy to see the 
  state of the dishwasher printed out each time you call a method which you can use to check your work.
  



The `DishWasher` class should have the following features:
Task Breakdown:

1. Define the Class and Instance Variables
   - Create a class named `DishWasher`.
   - Define the following instance variables:
     - `String brand`: The brand of the dishwasher.
     - `boolean isRunning`: A flag to track whether the dishwasher is currently running. Initialize it to `false`.
     - `int waterConsumptionPerCycle`: The amount of water used per cycle, measured in gallons. Initialize it to `0`.
     - `double totalEnergyUsed`: The total energy used by the dishwasher so far, measured in kilowatt-hours (kWh). Initialize it to `0`.

2. Create the Constructor
   - Implement a constructor that takes a `String` parameter for the brand of the dishwasher and initializes the `brand` instance variable.

3. Implement the `printStatus()` Method
   - Create a method that prints the current status of the dishwasher, including:
     - The brand of the dishwasher.
     - Whether the dishwasher is running.
     - The water consumption per cycle (in gallons).
     - The total energy used (in kWh).

4. Implement the `start()` Method
   - Create a `start()` method that:
     - Sets `totalEnergyUsed` to `0`.
     - Sets `isRunning` to `true`.

5. Implement the `stop()` Method
   - Create a `stop()` method that:
     - Sets `isRunning` to `false`.

6. Implement the `calculateEnergyUsed(double timeInMinutes)` Method
   - Create a method that calculates and returns the energy used based on the `waterConsumptionPerCycle` and the time the dishwasher has been running.
   - The formula for energy used is: `(waterConsumptionPerCycle * 1.34) + 0.15307107 * timeInMinutes`. (not a formula based on real numbers, 
        just random numbers for the sake of the exercise)

7. Implement the `preWash(double timeRunning)` Method
   - Create a `preWash(double timeRunning)` method that:
     - Sets `waterConsumptionPerCycle` to `3` gallons.
     - Calculates and adds the energy used during the pre-wash cycle to `totalEnergyUsed`.

8. Implement the `mainWash(double timeRunning)` Method
   - Create a `mainWash(double timeRunning)` method that:
     - Sets `waterConsumptionPerCycle` to `5` gallons.
     - Calculates and adds the energy used during the main wash cycle to `totalEnergyUsed`.

9. Implement the `dry(double timeRunning)` Method
   - Create a `dry(double timeRunning)` method that:
     - Sets `waterConsumptionPerCycle` to `0` gallons.
     - Calculates and adds the energy used during the drying cycle to `totalEnergyUsed`.


10. Implement the `runFullCycle()` Method
    - Create a composite method named `runFullCycle()` that:
      - Calls the `start()` method to begin the cycle.
      - Runs `preWash` for 10 minutes.
      - Runs `mainWash` for 40 minutes.
      - Runs `dry` for 30 minutes.
      - Calls the `stop()` method to end the cycle.

Final Step:

- Test Your Class:
  - Once you have implemented all the methods, create a `Main` class to test your `DishWasher` class.
  - Instantiate the `DishWasher` object, run a full cycle, and print the status to verify that all the methods are working correctly 
      (the brand should be samsung).

Expected Output:
- After running the full cycle and printing the status, you should see:
  Dishwasher Brand: Samsung
  Is Running: false
  Current Water Consumption: 0 gallons per cycle
  Total Energy Used: 19.9042642 kWh
